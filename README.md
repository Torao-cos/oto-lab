# おとラボ (Oto Lab)

中学理科「音の性質」・高校物理基礎「波・音」の授業用Webアプリ。
**オシロスコープ**（マイクで音の波形をリアルタイム観察）と**オシレーター**（2音源で正弦波・矩形波・三角波・ノコギリ波を発音、うなりの観察）を1画面で使えます。

🔗 **アプリを使う**: https://torao-cos.github.io/oto-lab/ （GitHub Pages）

## 特徴

- **インストール不要・無料・広告なし** — ブラウザで開くだけ（Chromebook / iPhone / Android / PC）
- **トリガー機能** — 本物のオシロスコープ同様、周期波形が静止して見える
- **固定スケールが既定** — 「大きい音＝大きい振幅」がそのまま見える（自動ゲイン調整も無効化）
- **2音源同時発音** — 440Hz + 444Hz で「うなり」を耳と目の両方で観察
- **凍結機能** — タップで波形を静止し、周期Tを読み取って f=1/T を計算する授業展開が可能
- **FFT表示** — 矩形波・ノコギリ波の倍音構造の観察（発展）
- **全停止ボタン・音量ランプ** — 教室での音事故対策

## 授業での使い方（例）

1. **音の大小と振幅**: 声の大きさを変えて波形の高さの変化を観察（固定スケールのまま）
2. **音の高低と振動数**: 高い声・低い声で波の密度と Hz 表示の変化を観察
3. **周期から振動数を計算**: 波形をタップで凍結 → 目盛りから周期を読む → f=1/T を計算して右上のHz表示と照合
4. **うなり**: 音源A=440Hz、B=444Hz を同時再生 → 1秒に4回のうなりを聴き、波形の「うねり」を見る
5. **波形と音色**: 同じ440Hzでも正弦波・矩形波・三角波・ノコギリ波で音色が違うことを聴き比べ、FFTで倍音を見る

## 技術仕様

- 単一HTMLファイル（外部ライブラリ・外部通信なし）
- Web Audio API + Canvas 2D
- マイク使用時は HTTPS が必要（GitHub Pages 上では問題なし）
- 自動ゲイン調整(AGC)・ノイズ抑制・エコーキャンセルを無効化したマイク入力
